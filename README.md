# Saikannan Sathish — Portfolio

Personal portfolio website showcasing my work, experience and skills as a Software Engineer and AI/ML Engineer.

**Live →** [saikannan.dev](https://saikannan.dev)

---

## Stack

| | |
|---|---|
| **Framework** | Next.js 16 (App Router) |
| **Styling** | Tailwind CSS v4 |
| **Animations** | GSAP + ScrollTrigger, Framer Motion |
| **Language** | TypeScript |
| **Deployment** | Vercel |

## Sections

| # | Section |
|---|---|
| 01 | Hero |
| 02 | About |
| 03 | Tech Stack |
| 04 | Projects |
| 05 | Experience |
| 06 | Contact |

## Highlights

- Scroll-triggered GSAP animations on every section
- Fully responsive with mobile hamburger navigation
- Custom SVG favicon and Open Graph image
- Dark theme with a consistent design token system
- Resume viewer at `/resume`
- SEO ready — sitemap, robots.txt and JSON-LD structured data

---

## Running Locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
